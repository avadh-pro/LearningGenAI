# LearningGenAI

Weekly Generative AI learning notes. Each week lives on its own branch:

| Branch | Topics |
|---|---|
| [LearningGenAI-Week1](../../tree/LearningGenAI-Week1) | Transformers, LLMs, and Generative AI fundamentals |
| [LearningGenAI-Week2](../../tree/LearningGenAI-Week2) | Open vs closed-source models, prompt engineering, vector embeddings, Hugging Face guide |
| [LearningGenAI-Week3](../../tree/LearningGenAI-Week3) | Retrieval Augmented Generation (RAG) and vector databases |
| [LearningGenAI-Week4](../../tree/LearningGenAI-Week4) | AI Agents: single and multi-agent architectures, LangGraph, agentic RAG, MCP servers |
| [LearningGenAI-Week5](../../tree/LearningGenAI-Week5) | Deployment and Evaluation of LLMs: model serving, GGUF/Ollama/vLLM, AWS/Cerebrium deployment, LLM evaluation |
| [LearningGenAI-Week6](../../tree/LearningGenAI-Week6) | LLMOps: guardrails, tracing, evaluation/monitoring, orchestration, observability |

```bash
git clone https://github.com/avadh-pro/LearningGenAI.git
```
